Your files. Your decisions.

Findspace runs on this computer. Choose one personal folder to index file names, paths, sizes and modified dates. No file contents are uploaded.

Find: search all indexed names and paths.
Space: spot large files and categories.
Organize: preview moves, select files, then apply.
Duplicates: compare exact contents; review copies yourself.

Moves stay on the selected filesystem and require hard-link support (such as NTFS or APFS). Unsupported locations are skipped. Undo skips edited files and occupied destinations. Avoid editing files during a move.

Refresh the index after changing files outside Findspace. Keep the launcher window open while using the app.
